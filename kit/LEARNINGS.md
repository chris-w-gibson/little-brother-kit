# Shared Learnings

Cross-companion lessons, distilled from what pilots hit and how it got solved. This is the
v0 of the "shared memory library" — curated and shipped with kit updates, **not** a raw dump
of anyone's usage. It only ever contains generalized, non-identifying lessons.

Your companion reads this file for context. It grows every time `companion update` runs.

---

## Working with your companion

- Use the signal prefixes (`NEED:`, `CONFIRM:`, `BLOCKED:` …). They're the difference between
  a companion that guesses and one that asks at the right moment. See CLAUDE.md.
- When you're stuck, say so out loud ("I'm stuck", "this isn't working"). The companion is
  built to treat that as a signal to change approach — and it's the most useful thing it can learn from.
